# Capture: как задавать запросы к FPF через MCP — рецепт на русском

**Источник:** сессия WP-109 (семинар 3), 2026-08-01 — полный проход «затруднение → паттерн → Solution → применение» на примере метода внесения данных замера (A.3.1/A.3.2).

## Три инструмента и когда какой

1. **Адрес неизвестен → `search_fpf`** (полнотекстовый поиск). 2–4 ключевых слова = предмет + действие с ним.
   Примеры из сессии: «мантра длинная мантра микромантра P2W»; «U.Transfer отношение передачи управляющий паттерн»; «локальная мантра метода спецификация метода».
2. **ID известен → `read_fpf_doc`**. Сначала `preview` (оглавление + размер страницы), потом `full` с лимитом 6000–9000 знаков — страницы 80–135K, целиком не читать; дочитывать до нужной секции.
3. **Нужен прикладной ответ → `query_fpf_spec`** (вопрос как эксперту, есть режимы compact/verbose/proof).

## Две формулы вопроса, которые срабатывают

- **Найти адрес:** «Какой паттерн управляет <предмет/отношение>?»
- **Вытащить Solution:** «Что обязано содержать <X> по <паттерн>? Дай точные обязательства / чек-лист».

Примеры из сессии:
- «Какие паттерны управляют: (1) структурой потока преобразований / таблицей позиций (E.18); (2) U.Transfer; (3) описанием многоразового метода, чтобы другой человек мог выполнить работу?»
- «A.3.1 U.Method и A.3.2 U.MethodDescription: что обязано содержать заявление метода (Solution)? Что обязано содержать описание метода, чтобы другой человек выполнил его без автора? Дай точные обязательства обоих паттернов».

## Правила точности

- **Имена паттернов в вопросе** (E.18, A.3.1) заметно повышают точность — адреса из семинаров, слайдоментов и таблиц копить.
- Корпус на английском: по-русски отвечает, но английские термины-ключи (`method`, `transfer`, `mantra`, `work plan`) бьют точнее. Рабочий приём: вопрос по-русски, термины — английскими.
- **Подстановку делает человек**: корпус даёт обязательства; «яблоки из жизни» подставляешь сам (семинар 3: сигнатура и параметры).

## Почему это E.18.1 в действии

Цикл «затруднение → search/query → паттерн → Solution → применение к своему случаю → результат или честная остановка» — это локальная P2W-мантра, где шаг «применить паттерн» выполняет MCP вместо чтения спецификации вручную.
