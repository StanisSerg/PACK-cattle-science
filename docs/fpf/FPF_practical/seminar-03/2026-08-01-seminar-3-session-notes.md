## Что узнал (различения семинара 3)

- **Мантра** — короткая повторяемая формулировка, держащая Solution паттерна во внимании (FPF: «a short repeatable formulation that keeps its Solution in attention»). Длинная удерживает проект, микромантра — один переход. Мантра ≠ метод/план/приказ: исполняемое условное продолжение — только CGUS (A.22.CGUS).
- **Большая P2W (8 ходов, карта из 12 позиций):** принятая проблема + критерий → стратегирование → пригодный метод → приспособленный метод → план + готовность → работа → преобразование (связь работа↔преобразование устанавливается отдельно!) → измеренные значения → оценка. Три красные ветки отказа делают карту рабочей.
- **Работа равна нулю:** усилие без преобразования — не работа (блокнотик технолога: замер есть, данных в системе нет).
- **Место входа:** мантру выбирают по нужному итогу, место входа — по первому недостающему/неподтверждённому результату.
- **Как пользоваться корпусом:** один вопрос за раз (FPF одноходовый); не «предложи карточку» (гадайка), а «затруднение + какой результат нужен для какого перехода» (E.11, E.18.1).
- **A.3.1 U.Method:** идентичность метода = participant meanings + applicability + conditions + intended effect + bounds; три независимости (description/run/assignment).
