## Что вынести на семинар 5 (DPF/LPF)

**Кандидаты в LPF технологического отдела** (из WP-109, ветви B-01..B-03):

1. **Метод B** (гранулированный допуск + лёгкий сигнал) — method claim готов (`full-cycle/05-method-claim.md`), на приёмке пилота. 4 пробела до передачи: содержимое списка допуска D1, формат сигнала, правило эскалации, пороги способностей.
2. **Описания D1–D4** (A.3.2 — несколько описаний одного метода по аудиториям): список допуска, карточка сигнала, правило подтверждений, инструкция для персонала.
3. **Два лица описания метода** (E.17, практика С4-П2 от 08.08): вариант для помощника + вариант для руководства — живой пример multi-view публикации для LPF.
4. **Карточка огрубления** (A.6.3.CSC, практика С4-П6 от 07.08): сводка для руководителя с возвратом к точности.
