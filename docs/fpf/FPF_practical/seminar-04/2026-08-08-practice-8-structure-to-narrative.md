# П8 — Структуру в рассказ с явным возвратом (A.6.3.NAR)

## 0. Задание (по слайдам семинара 4, слайд 158)

Взять сложный материал проекта → связный учебный рассказ для названного читателя и работы, с явной фиксацией: исходная эпистема `X`, кандидат `Y`, тот же `EntityOfConcern`, схемы отсчёта, сохранённое/потерянное, неподдерживаемый более сильный вывод, условие возврата к `X`. Приёмка: NSTD.7 (носитель ≠ допущенная версия, владелец допуска) → NSTD.6 (оценка версии).

## 1. Читатель и работа (названы ДО рассказа)

- **Читатель:** пилот (руководитель консультационной практики; сам на визите не был).
- **Работа читателя:** решить следующий ход по хозяйству СХПК Битимский — что включить в коммерческое предложение по кормовым добавкам и на какие проблемы хозяйства опереться.
- **Что читатель обязан уметь восстановить после чтения:** (а) фактуру хозяйства (поголовье, продуктивность, используемые добавки); (б) проблемные зоны, названные хозяйством; (в) договорённость и следующий шаг; (г) какие цифры шумные и требуют сверки.

## 2. Исходная эпистема X

- **X:** автоматическая транскрипция аудиозаписи визита (Plaud), 36 минут, 4 спикера: Станислав (поставщик, Беларусь), Speaker 1 (коллега поставщика, хозяин разговора), Speaker 4 (представитель хозяйства — зоотехник/управляющий), Speaker 2 (второй представитель).
- **Качество X:** сырое ASR — термины искажены («хорит-порит» ≈ холин, «готёс» ≈ отёл, «аистокетоз» ≈ антикетоз, «карманная жарка» ≈ карнаж/зерно), спикеры местами перепутаны, часть фраз не восстановима.
- **EntityOfConcern (один и тот же в X и Y):** визит поставщиков в СХПК Битимский 2026-02-10 — фактура хозяйства, его проблемы и договорённости по добавкам.

## 3. Рассказ (кандидат Y)

**Правило порядка рассказа:** контекст визита → фактура хозяйства → проблемные зоны (в порядке, названном хозяйством: кормовая база, здоровье, рынок) → договорённость. Порядок выбран так, чтобы читатель сначала получил рамку (кто, где, зачем), затем проверяемые факты, затем решения.

---

В феврале к хозяйству СХПК Битимский приехали поставщики кормовых добавок — Станислав из Беларуси с коллегами. Хозяйство встречало их в тяжёлый момент: с утра пришли новости, что заводы не платят за молоко, а ценовое давление на производителей усиливается. Сам представитель хозяйства к кризисам привык — по его словам, они повторяются каждые три-пять лет, и однажды хозяйство пережило такой период, просто перестав покупать что-либо извне.

Хозяйство крупное: 1046 дойных коров, суточный надой порядка 26 тонн (цифра из разговора, требует сверки). Добавки используют умеренно: холин хлорид до 50 г, слабый анионный премикс (≈200–250 г, «для галочки», по самооценке хозяйства), гепатопротектор по 350 руб/голову, пропиленгликоль — профилактически после отёла через день по 200 г до двух месяцев. Защищённые жиры не используют вовсе.

Первая проблемная зона — кормовая база. Кукуруза на местных полях не вызревает: крахмал в силосе 22% при норме 30–33%. Хозяйство пробует выход через «карманную жарку» (зерно), в прошлом году заложили 250 га, но технология ещё не отработана — «приори много, не добрались». Силос зелёный, риск ацидоза при некорректированном рационе уже проявлялся.

Вторая зона — здоровье после отёла. Неедение свежих коров — постоянная боль: хозяйство вливает вручную по 20 литров по полчаса на корову. Практикуют вправление смещения рубца (методика с двумя проколами, без полостной операции — обучали у коллег из Сухоловского), кесарево на живую в осложнённых случаях. Протокол поставщика на такие случаи — 500 г пропиленгликоля в двух литрах тёплой воды три дня подряд.

Третья зона — рынок. Заводы задерживают платежи; хозяйство уже проходило цикл «перестали покупать добавки → потеряли раздой → долго восстанавливали» и знает его цену. Поставщики аккуратно используют это в аргументации: белорусский опыт говорит, что экономия на добавках в кризис оборачивается дороже.

Договорённость по итогам: хозяйство передаёт, что использует сейчас; поставщики готовят предложение — составы и ценовой диапазон, с ориентацией на индивидуальную рецептуру под хозяйство («основная ориентация — разработка индивидуальных рецептов»). Следующий контакт — четверг.

## 4. Запись NAR (конструкция c : X → Y)

| Строка | Значение |
|---|---|
| **Исходная эпистема X** | Транскрипт Plaud (108 реплик, таймкоды), файл `02-10-Консультация-СХПК-Битимский__261a2958.txt` |
| **Кандидат Y** | Рассказ раздела 3 (выше), русская проза, ~450 слов |
| **EntityOfConcern** | Визит 2026-02-10 в СХПК Битимский: фактура + проблемы + договорённости. Тождество сохранено — рассказ о том же визите, не «о типичном хозяйстве» |
| **Схемы отсчёта X / Y** | X: таймкоды + спикеры (навигация по аудио); Y: тематические абзацы (контекст → фактура → проблемы → договорённость). Отношение: каждый абзац Y ссылается на диапазон реплик X |
| **Сохранено** | Поголовье и надой; перечень добавок с дозировками как названы; крахмал 22% vs 30–33%; протоколы пропиленгликоля (профилактический и лечебный); рыночный контекст; договорённость «предложение к четвергу» |
| **Потеряно (явно)** | Имена участников и второстепенные персоны (Заваевский, врачи); бытовые истории (забойщик, мухи/курповед, врач-алкоголик) — не влияют на работу читателя; эмоциональный регистр разговора; точная атрибуция части реплик |
| **Шумное в X → помечено в Y** | «26 тонн» (надой — помечен «требует сверки»); «карманная жарка» (термин не распознан, оставлен в кавычках); «аистокетоз» ≈ антикетоз; дозировка гепатопротектора (350 руб — цена, не доза; дача 75 г vs 250–300 г — в X противоречие, в Y не разрешено) |
| **Неподдерживаемый более сильный вывод** | «Хозяйство купит продукт» — не обосновано (договорённость только о предложении); «протокол пропиленгликоля эффективен» — в X только анекдотические подтверждения; точные дозировки как рекомендация — недопустимо: в Y это «как названо хозяйством», не норма |
| **Условие возврата (reopen trigger)** | Любая цифра или факт, попадающие в коммерческое предложение или протокол → возврат к X (аудио по таймкоду), а лучше — прямая сверка с участником визита. Также возврат, если читатель готовит материал для третьих лиц (другой PublicationScope) |

## 5. Приёмка

**NSTD.7 — носитель ≠ допущенная версия.** Сгенерированный носитель — этот файл. Допуск к использованию: это учебно-повествовательное применение (не архитектурный синтез — C.35/C.32 неприменимы); **владелец допуска — пилот** (владелец консультационной методики и единственный, кто может сверить фактуру с участниками).

**NSTD.6 — проверка версии (после допуска пилотом):**

| Критерий | Статус |
|---|---|
| Опорный материал назван и доступен | ✅ X с путём и таймкодами |
| Восстановимость выбранной структуры | ✅ правило порядка названо; каждый блок Y возвращается к репликам X |
| Агентность | ✅ спикеры названы по ролям, где ASR уверен; неуверенность помечена |
| Объявленные потери | ✅ раздел 4, строка «Потеряно» |
| Пригодность для читателя и работы | ⏳ проверяет пилот: достаточно ли для решения о следующем ходе |
| Возврат к источнику | ✅ reopen trigger сформулирован |

**Проверка восстановления (через паузу, по слайду):** пилот — без подсказки назови: исходный материал, две существенные связи (например: «крахмал 22% → риск ацидоза → осторожность с рекомендациями по рациону»), паттерн для их проверки (A.6.3.NAR / C.2.P для цифр), и работу, в которой рассказ можно использовать.
