# Практика 4 (семинар 4): восстановление точности фразы-критерия

## Исходный фрагмент

**Фраза:** «Понятная система потоков отчётов: чётко кто пишет, куда пишет, какую информацию, как информация используется и обрабатывается; цикл замыкается до действия; учёт ведут помощники, а не пилот»

**Контекст:** `dept-practices/branches/B-01-report-control/B-01.D-01-p2w-unfolding-report-control-system.md`, позиция 2 «Критерий изменения» большой P2W-развёртки проекта «Система контроля отчётов технологов». Позиция отмечена ✅ (считается достигнутой).

**Следующая работа:** позиции 7–8 — описать потоки и назначить/обучить помощников; приёмка готовности (позиция 7) опирается на критерий позиции 2.

**Нужный вывод из фразы:** «потоки описаны достаточно, чтобы учёт вёл помощник без пилота — можно переходить к назначению».

## Выбор режима

Применяю `C.2.P` с заимствованием тестов `E.10`: фраза — проектный текст без FPF-терминов и без заявления соответствия FPF, поэтому вердикт по E.10 не выносится, распаковываем обычное выражение.

## Обычный предполагаемый смысл

«Мы понимаем, как должны ходить отчёты, и хотим, чтобы текущий учёт вели помощники, а не пилот».

## Восстановление: предмет, утверждение, типы, отношения

Фраза выглядит как один критерий, но говорит о **трёх разных предметах** (коллапс «утверждение / представление / выполненная работа», слайд 70):

1. **Описание системы потоков** — это эпистема (запись о потоках: кто, куда, что, как обрабатывается). Утверждение: «описание существует и понятно». «Понятная» — без названного читателя: пилоту потоки понятны уже сейчас; понятны ли они помощнику — неизвестно, читатель не назван (viewpoint без аудитории).
2. **Фактический цикл «отчёт → действие»** — это выполненная работа и преобразование, не описание. Утверждение: «цикл замыкается до действия». Но фактура самой развёртки (позиция 9, 🔴): «связь сводка → вмешательство не установлена, эпизодическая». То есть на момент ✅ цикл **не замкнут** — критерий противоречит собственной карте.
3. **Назначение исполнителя учёта** — это назначение роли (кто выполняет работу учёта), а не свойство системы потоков. Фактура (позиция 8, 🔴): «исполнитель = сам пилот вручную». На момент ✅ помощники не назначены.

Итого: одна фраза-критерий смешала три независимо проверяемых утверждения, из которых два на момент простановки ✅ не выполнялись. Область применимости (ClaimScope) тоже не названа: все отчёты хозяйства или только сводка по молоку CASE-002.

## Предметный паттерн

Переход от слов к паттернам: `C.2.1` (эпистема: содержание vs редакция — «понятность» есть только для названного читателя), `A.2.1` (назначение роли — исполнитель устанавливается отдельным фактом, не свойством системы), `A.15.5` (готовность к работе — критерий входа должен быть проверяемым). Профиль проверяемости — F/G/R из семинара 4: у фразы не заданы область применимости (G) и способ проверки (R).

## Точная формулировка (одна фраза → три проверяемых утверждения)

> **Критерий позиции 2 (редакция 2026-08-02):**
> 1. **Описание потока:** для сводки по молоку названы писатель, носитель, поля данных, читатель и работа читателя по каждому потоку. Проверка: помощник читает описание и ведёт поток без вопросов к пилоту.
> 2. **Замкнутость цикла:** на каждое отклонение в сводке есть запись о решении (вмешательство или сознательное невмешательство) в тот же период. Проверка: выборка последних N сводок.
> 3. **Исполнитель учёта:** учёт по потоку ведёт назначенный помощник. Проверка: журнал за 2 недели без эпизодов «учёл пилот».

## Для какого вывода даёт основание

«Позиция 2 закрыта честно: часть 1 выполнима описанием (уже частично есть в D-02), части 2–3 — это и есть работа позиций 7–8». Следующая работа выполнима без угадывания: писать описание потоков под читателя-помощника и назначать исполнителя.

## Какой более сильный вывод НЕ обоснован

«Система потоков отчётов готова к передаче помощникам» — не следует: замкнутость цикла и назначение исполнителя фактически не выполнены (позиции 8–9 🔴). Статус ✅ у позиции 2 в старой редакции — иллюстрация слайда 74: «утверждение не становится более обоснованным из-за красивой публикации».

## Предлагаемое действие по проекту

Обновить редакцию критерия позиции 2 в `B-01.D-01` на три проверяемых утверждения (выше) и сменить статус позиции 2 с ✅ на ◐ (часть 1 — в работе, части 2–3 — не начаты). Решение — за пилотом.
