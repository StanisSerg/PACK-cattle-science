# П3 — Сохранить раннюю зацепку, не превращая её в уверенный диагноз (A.16.1)

> **Паттерн:** A.16.1 PreArticulationCuePack — первая честная форма публикации для содержания, которое ещё нельзя выпускать как утверждение, диагноз, выбранный маршрут или запись о работе, но которое жалко потерять. Форма: ядро зацепки + причина сохранения + главный свидетель + видимые ветви разбора. **Запрещено:** выбирать маршрут, ставить диагноз, придумывать обоснование.
> **Применение (из WP-109):** сигналы с фермы до диагноза — здоровье стада.

## 1. Исходный материал

Живая ситуация с ферм (прозвучала на визите в Битимский 10.02, реплики 79–86: «3 коровы не едят… вручную по 20 литров, полчаса коровы есть… заливаем пропиленгликоль после отёла»): **скотник сообщает «корова после отёла не ест»** — и на ферме этот сигнал обычно сразу превращается либо в диагноз («кетоз — заливай»), либо в действие (заливают «на всякий случай»), либо теряется вовсе («посмотрим завтра» — и забыли).

## 2. Различения A.16.1 (что в материале на самом деле)

| Уровень | Содержание в нашем случае |
|---|---|
| **Сырой сигнал / источник** | Скотник на обходе: корова №___ (3-й день после отёла) не подошла к кормовому столу; вчера ела вполсилы. Источник — глаза скотника, не прибор |
| **Наблюдаемый симптом** | Отсутствие/снижение потребления корма в первые дни после отёла. Это ещё не «болезнь» — это наблюдение о поведении |
| **Ранняя зацепка (ядро)** | «Не ест 2-й–3-й день после отёла» — стоит сохранить именно в этой формулировке: она открывает ветки, но ни одну не выбирает |
| **Возможные догадки (НЕ диагнозы)** | (а) субклинический кетоз; (б) смещение рубца; (в) метрит/эндометрит; (г) гипокальциемия; (д) мастит; (е) стресс/травма без патологии. Каждая — только кандидат на ветку разбора |

## 3. Cue pack (форма сохранения)

- **Ядро зацепки:** «корова №___ не ест, N-й день после отёла, дата, смена».
- **Причина сохранения:** от этого сигнала зависят разные ветки лечения с разной ценой ошибки; потерянный сигнал = поздний диагноз = потерянная корова или лактация.
- **Главный свидетель / опора:** скотник (наблюдение); измеримые опоры, доступные немедленно — температура, кетоны в моче/молоке (тест-полоски), потребление корма.
- **Ветви разбора (кандидаты, не маршруты):**
  1. Тест на кетоны → кетоз-ветка (пропиленгликоль по протоколу);
  2. Аускультация рубца / проверка смещения → хирургическая ветка (вправление по Киселёву);
  3. Гинекологический осмотр → метрит-ветка;
  4. Ничего не измерено — наблюдение 24 ч с фиксацией (самая слабая ветка, но честная).
- **Чего в pack НЕТ (и не должно быть):** слова «кетоз» как заключения, назначения, записи о лечении. Лечение — отдельная публикация после проверки.

## 4. Какое новое различение нужно для перехода к B.4.1 (Observe → Notice → Stabilize → Route)

Сейчас на ферме не хватает **единицы стабилизации наблюдения**: разницы между «один скотник один раз заметил» и «зафиксировано в стойком виде, видно ветеринару». Практически это: форма фиксации (строка в журнале/Telegram: № коровы, день после отёла, признак, кто заметил) + порог маршрутизации (2-й день неедения → обязательный осмотр ветеринаром). Пока этого различения нет, любой «маршрут» — на самом деле привычка («заливаем всегда»), а не выбранный маршрут.

## 5. Проверка по заданию (слайд 57)

| Проверка | Результат |
|---|---|
| Источник / симптом / зацепка / догадки различены | ✅ раздел 2, четыре отдельные строки |
| Маршрут не выбран, диагноз не поставлен | ✅ ветки названы кандидатами; лечение не назначено |
| Обоснование не придумано | ✅ «причина сохранения» — не обоснование диагноза, а цена потери сигнала |
| Названо различение для следующего шага (B.4.1) | ✅ раздел 4 — единица стабилизации наблюдения |
| Неопределённость сохранена без потери продолжения | ✅ ветка 4 (наблюдение 24 ч) — честный минимум, а не «подождём» |
