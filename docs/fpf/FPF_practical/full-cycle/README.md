# Полный цикл FPF — практика

> Прохождение всего пути от сигнала до проверки языка на одном реальном кейсе.
> Каждый шаг — отдельный файл `NN-название.md` по карте из руководства (`../2026-08-02-fpf-workflow-guide.md`).
> Правило: решения принимает пилот; агент применяет паттерны; один шаг — один файл — один следующий ход.

## Кейс

**Предмет:** задержка информации о визитах помощников → несделанные в моменте изменения на ферме (учёт в Telegram, хозяйство в РБ)
