# 06 — P2W-развёртка: «Своевременное замыкание цикла визита»

> Карта выражает зависимость результатов, а не очередь работ (мантра ≠ план).
> Фактура — только из артефактов шагов 01–05 этого цикла; статусы честные, не желаемые.

## Карта (12 позиций)

| # | Позиция | Содержание применительно к проекту | Статус |
|---|---------|-------------------------------------|--------|
| 1 | Принятая проблема | Карточка `01-problem-card.md`: цепочка «визит → информация → действие» рвётся по времени; not-wish отсечены | ✅ (принята де-факто: пилот пошёл дальше) |
| 2 | Критерий изменения | Доля визитов с выполненными в день изменениями + медианное время «визит → изменение»; целевой порог не задан | ◐ (форма есть, порога нет) |

## Место входа (самый ранний неподтверждённый переход)

**Переход 5→6.** Позиции 1–4 имеют обоснованные результаты; позиция 5 — черновик с пробелами; позиция 6 — первый полностью отсутствующий результат: **нет плана конкретной работы по внедрению метода**.

Анти-паттерн, которого избегаем: не начинаем с позиции 8 («давайте просто начнём пользоваться») — последний заметный симптом, а не самый ранний разрыв.

## Паттерн для результата следующего перехода

Результат перехода 5→6 — **план конкретной работы**: паттерн `A.15.2` (U.WorkPlan).

Содержание плана (черновик позиций для согласования с пилотом):

1. Замер базовой линии: просмотр Telegram-журнала за последние N недель — доля визитов с в-срок изменениями, медианное время (закрывает позиции 10–11 частично).
2. Пилот заполняет список допуска D1 (цена ошибки по типам изменений) и правило эскалации D3.
3. Встреча-инструктаж помощников (D1+D2, ≤30 мин).
4. Старт пилота метода: дата, длительность 4–6 недель.
5. Замер после 4–6 недель → переход к позиции 12 (решение).

Для позиции 7 (готовность) следующий за ней паттерн — `A.15.5` (Work-Entry Readiness): проверка «описания написаны, помощники ознакомлены, окно подтверждений задано» до старта пилота.

## Красные ветки (напоминание)

- Изменение не подтверждено после пилота → диагностировать: метод (список допуска), выполнение (сигнал не отправляется), причинную гипотезу (мотивация, не форма).
- Нет готовности (позиция 7 🔴 к дате старта) → не стартовать: build-the-builder (дописать D1–D4), а не «разберёмся в процессе».
