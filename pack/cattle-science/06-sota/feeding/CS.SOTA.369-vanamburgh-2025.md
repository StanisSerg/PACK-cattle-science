# 2. РЕЗЮМЕ ИСТОЧНИКА

## 2.1. О чём выступление

Презентация новой субмодели CNCPS (входит в v6.5.6, далее v7), которая впервые нормирует **изокислоты** (разветвлённые ЛЖК: изовалериат, 2-метилбутират, изобутират) — облигатный фактор роста фибролитических бактерий, известный с 1960-х, но десятилетиями игнорировавшийся моделью. Теперь рядом с энергия- и азот-allowable бактериями считается изокислота-allowable, и микробный поток оценивается по **минимуму из трёх** (для пула переваримого NDF).

## 2.2. Key Claims

**Claim 1: У фибролитиков облигатная потребность в изокислотах — одного азота недостаточно.**
- **Утверждение:** Фибролитические бактерии не синтезируют BCAA эффективно и не захватывают BCAA/пептиды; им нужны изокислоты для построения своих BCAA. Нормирование всех бактерий только по азоту — недооценка истинной потребности.
- **Evidence:** Знание с 1960-х (микробиология рубца); изложено как обоснование субмодели.
- **Уверенность:** 0.9 (консенсусная микробиология; в выступлении — без новых данных).
- **Цитата:** "since 1960 we've known that the fibrolytic bacteria have a requirement for branch chain VFAs" (транскрипт, 00:45).

**Claim 2: Рацион может быть обеспечен по энергии и азоту, но дефицитен по изокислотам.**
- **Утверждение:** Пример рациона (27 кг DMI): энергия-allowable 4218 г, азот-allowable 5377 г (130 %), изокислота-allowable 4053 г → дефицит ~165 г микробного роста, невидимый до субмодели.
- **Evidence:** Расчётный пример из выступления; полевые случаи (центральный Нью-Йорк), где поднятие растворимого истинного протеина решало «необъяснимые» рационы.
- **Уверенность:** 0.75 (расчёт + полевые наблюдения автора; нет опубликованной валидации).
- **Цитата:** "when we run the branch chain VFA allowable all of a sudden we find out we're at 4,053... we're deficient" (транскрипт, 17:17).

**Claim 3: Микробный поток v6.5.6 = минимум из энергии/азота/изокислот-allowable (только для переваримого NDF).**
- **Утверждение:** Если изокислота-allowable ниже энергия-allowable, снижается число фибролитиков и переваривание NDF. Базовые расчёты энергии/азота не меняются.
- **Evidence:** Описание логики субмодели в выступлении.
- **Уверенность:** 0.8 (задекларированная логика версии 6.5.6).
- **Цитата:** "6.5.6 will utilize the minimum either energy, nitrogen, or branch chain VFA bacteria nutrient support to estimate bacterial flow" (транскрипт, 19:24).

**Claim 4: Риск дефицита выше на рационах с высокой долей ферментируемых углеводов.**
- **Утверждение:** ≥ 14 % СВ ферментируемого NDF → ощутимая потребность в изокислотах; > 42 % СВ ферментируемых углеводов → амилолитики забирают произведённые изокислоты обратно (оппортунизм), создавая дефицит для фибролитиков.
- **Evidence:** Пороги названы в выступлении без ссылок на первичные исследования.
- **Уверенность:** 0.65 (практические ориентиры автора; требуют верификации по литературе).
- **Цитата:** "diets that are greater than 42% of the dry matter fermentable carbohydrates can limit iso acid supply" (транскрипт, 22:10).

**Claim 5: Целевые маркеры — true RDP и аммиачный баланс.**
- **Утверждение:** True RDP (растворимый протеин − аммиак) > 9 % СВ; аммиачный баланс рубца ≥ 125 % (комфортно 125–130 %); сверка — 185–215 г true RDP на кг ферментируемых углеводов (84–98 г/фунт).
- **Evidence:** Значения из выступления («we want», «we find» — нормы текущей версии модели).
- **Уверенность:** 0.7 (модельные нормы; не исходные исследования).
- **Цитата:** "we want this number right now to be greater than 9% of the dry matter... greater than 125%" (транскрипт, 23:23).

# 3. ВВЕДЕНИЕ

## 3.1. Контекст и значимость проблемы

Эпоха снижения азота в рационах обнажила старый пробел: раньше избыток пептидов (нормировка под амилолитиков) инцидентно закрывал потребность фибролитиков в изокислотах. При снижении азота рационов этот «страховочный избыток» исчез, и скрытый дефицит начал проявляться у высокопродуктивных коров как необъяснимое недовыполнение рациона по молоку.

## 3.2. Почему сейчас

- Снижение азота рациона (экология, экономика) — убран избыточный пептидный буфер.
- Субмодель готовилась с ~2008 г.; реализована под руководством Эндрю ЛаПьера; входит в v6.5.6.
- Расчёты касаются только рубцовых предсказаний: рост бактерий на пуле переваримого NDF.

# 4. СТРУКТУРА РАСЧЁТА МОДЕЛИ

## 4.1. Что не меняется (v6 → v7)

| Блок | Логика |
|----------|----------|
| Пулы углеводов | A1 ЛЖК, A2 лактат, A3 прочие ОК, сахара/фруктаны, крахмал, растворимая клетчатка, B3 переваримый NDF, C |
| Переваривание | KD/(KD+KP); KP по паре фураж/концентрат, DMI, живой массе; фуражная KP из NorFor |
| Рост бактерий | km (поддержание), KD ≈ скорость роста, YG = 0,04 г бактерий/г углеводов/час (v6.5) |
| Азот | Аммиак рациона + расщепляемый протеин + рециркуляция мочевины → азот-allowable |

## 4.2. Что добавлено

**Снабжение изокислотами:** оборот бактерий + оборот простейших (в v6.5 косвенно) + пептидный баланс + экзогенная добавка → профиль BCAA бактерий → изокислота-allowable бактерии (только фибролитики / переваримый NDF).

**Метаболический мост:** амилолитики деаминируют лейцин/изолейцин/валин → изовалериат, 2-метилбутират, изобутират → фибролитики захватывают и интерконвертируют обратно в BCAA.

# 5. ПРИМЕРЫ ИЗ ВЫСТУПЛЕНИЯ

## 5.1. Скрытый дефицит

Рацион 27 кг DMI: энергия 4218 г / азот 5377 г (130 %) / изокислоты 4053 г → дефицит ~165 г микробного роста. До субмодели рацион выглядел полностью обеспеченным.

## 5.2. Коррекция добавкой

Рацион на 97 фунтов молока (~44 кг): энергия 4580 г, азот 5400–5500 г, BCAA-allowable 4430 г (дефицит по 2-метилбутирату и изовалериату) → недополучено ~4–5 фунтов MP-allowable молока. Добавка изокислот: BCAA-allowable 4600 г > энергия-allowable → целевые 97 фунтов достигнуты, ME и MP выровнены.

# 6. ИНТЕРПРЕТАЦИЯ

1. **Третий лимитирующий фактор стал измеримым.** «Азота достаточно» больше не означает «микробам всего достаточно» — первый лимит может быть изокислотным.
2. **Экология ниш объясняет динамику:** амилолитики — оппортунисты; на крахмалистых рационах они производят изокислоты и тут же реутилизируют их — перекрёстное кормление фибролитиков падает.
3. **Это уточнение, не революция:** по оценке автора, большинство рационов не изменится; ценность — объяснение «недодающих» рационов.

# 7. КРИТИЧЕСКИЙ АНАЛИЗ

## 7.1. Сильные стороны

- **Механистическая база консенсусна** (облигатная потребность фибролитиков — знание с 1960-х).
- **Минимально инвазивно:** базовые расчёты модели не меняются, добавлена одна строка баланса.
- **Практические пороги** (14 %/42 % СВ, true RDP, аммиак) сразу применимы в формуляции.

## 7.2. Ограничения

**По источнику:**
- **Видео-презентация, не рецензируемая статья:** нет данных валидации субмодели, нет ссылок на первичные исследования порогов.
- **Числа порогов** (9 %, 125 %, 185–215 г/кг) даны как нормы модели, без экспериментального обоснования в источнике.
- **Примеры рационов** — иллюстративные расчёты, не полевые испытания.

**По переносу:**
- Субмодель новая (v6.5.6) — поведение на российских рационах (высокая доля фуража, иная химия кормов) не проверено; пороги требуют локальной сверки.
- Учёт простейших в v6.5 косвенный — точность оценки снабжения изокислотами ограничена.

# 8. ВЫВОДЫ

## 8.1. Структурировано

1. Изокислоты — облигатный фактор роста фибролитиков; азот его не заменяет.
2. v6.5.6 считает микробный поток по минимуму из трёх allowable — только для переваримого NDF.
3. Дефицит проявляется на рационах ≥ 14 % СВ ферментируемого NDF и > 42 % СВ ферментируемых углеводов.
4. Маркеры: true RDP > 9 % СВ, аммиак ≥ 125 %, 185–215 г true RDP/кг ферментируемых углеводов.
5. Коррекция: добавка изокислот или поднятие растворимого истинного протеина.

## 8.2. Ключевые сообщения для лекции

1. «Азота достаточно» ≠ «микробам всего достаточно» — изокислотный лимит стал видимым.
2. Амилолитики — ненадёжные поставщики изокислот: на крахмалистых рационах забирают своё обратно.
3. Инструмент уточняющий: большинство рационов не изменится, но «недодающие» получат диагноз.

# 9. FAQ

**Вопрос 1: Почему фибролитики не могут обойтись азотом?**
Ответ: Они не синтезируют разветвлённые аминокислоты эффективно и не захватывают готовые BCAA/пептиды (это ниша амилолитиков). Изокислоты — единственный их путь построить BCAA; азот (аммиак) даёт только азотную часть.

**Вопрос 2: Откуда берутся изокислоты в рубце без добавок?**
Ответ: Оборот бактерий и простейших, пептидный баланс — амилолитики деаминируют BCAA и «делятся» изокислотами. Но на богатых крахмалом рационах они забирают их обратно — возникает дефицит.

**Вопрос 3: Что проверить в рационе первым?**
Ответ: Долю ферментируемого NDF (≥ 14 % СВ — повышенная потребность) и долю ферментируемых углеводов (> 42 % СВ — риск дефицита), затем true RDP (> 9 % СВ) и аммиачный баланс (≥ 125 %).

**Вопрос 4: Изменит ли субмодель мои рационы?**
Ответ: По оценке автора — большинство не изменится. Ценность в диагностике: рационы, которые «не доходили» по молоку при формально полном балансе, могут оказаться изокислотно-дефицитными.

**Вопрос 5: Это про все углеводы?**
Ответ: Нет. Изокислотный баланс касается только пула переваримого NDF (фибролитики). Крахмал и сахара — ниша амилолитиков, у них другая система нормирования (пептиды + аммиак).

# 10. ПРАКТИЧЕСКОЕ ПРИМЕНЕНИЕ

## 10.1. Алгоритм проверки рациона на изокислотный риск

1. Оценить долю ферментируемого NDF и ферментируемых углеводов в СВ (пороги 14 % и 42 %).
2. Проверить true RDP (растворимый протеин − аммиак) — цель > 9 % СВ.
3. Проверить аммиачный баланс рубца — цель ≥ 125 % (комфортно 125–130 %).
4. Сверить г true RDP/кг ферментируемых углеводов — ориентир 185–215.
5. При дефиците: добавка изокислот или поднятие растворимого истинного протеина; пересчитать рацион.

## 10.2. Типичные ошибки

- **Судить об обеспеченности микробов только по аммиачному балансу** — изокислотный лимит невидим.
- **Применять изокислотный баланс ко всем углеводам** — только переваримый NDF.
- **Ждать эффекта на всех рационах** — субмодель диагностическая, не перестройка норм.

## 10.3. Пограничные сценарии

- **Высокофуражный рацион (много переваримого NDF)** — максимальная потребность в изокислотах: проверка обязательна.
- **Высококрахмалистый рацион** — оппортунизм амилолитиков: риск дефицита для фибролитиков и падения переваримости NDF.
- **Рацион «не доходит» по молоку при балансе 125–130 % по азоту** — первый кандидат на проверку изокислот.
