# 2. АННОТАЦИЯ (Abstract)

## 2.1. Перевод Abstract

Резилентность (устойчивость к возмущениям) сельскохозяйственных животных была предложена как индикаторный признак здоровья и жизнеспособности. Один из подходов — анализ дисперсии и автокорреляции суточных надоев; другой — использование суточного времени жвачки (RT) как индикатора состояния здоровья, для чего современные мониторинговые бирки дают точные суточные данные на больших поголовьях. Авторы вычислили генетические корреляции между средними, логарифмами дисперсий и автокорреляциями суточного надоя и времени жвачки, пятью метаболическими болезнями (задержание последа, метрит, кетоз, смещение сычуга, родовой парез), семью признаками израильского селекционного индекса и упитанностью (BCS) вокруг отёла. Первые 40 дней лактации (DIM) и остаток лактации 40 860 первотёлок, отелившихся в 2019–2024 гг., анализировались раздельно. Значимые генетические корреляции индикаторных признаков резилентности выявлены для всех пяти болезней, BCS и всех семи индексных признаков. Логарифм дисперсии суточного надоя за первые 40 DIM имел наследуемость 0,11 и оказался лучшим индикатором резилентности среди тестированных; его корреляция с инцидентностью кетоза составила −0,62. Коэффициенты детерминации племенной ценности по израильскому индексу на основе семи индикаторных признаков, вычисленных за 1–40 DIM, составили 0,18 для коров и 0,19 для производителей. Включение предикторного признака резилентности, основанного на первых 40 DIM, в селекционный индекс обосновано для улучшения отбора молодых коров и производителей (Weller and Ezra, 2026, p. 6416).

## 2.2. Key Claims

**Claim 1:** Отрицательный логарифм дисперсии суточного надоя за первые 40 DIM (−LnVar молока) — лучший индикатор резилентности среди тестированных.
- **Утверждение:** Наследуемость −LnVar молока 1–40 DIM = 0,115 (SE < 0,016); именно этот признак имел наибольшие по модулю генетические корреляции с болезнями и был лучшим индикатором для болезней по сравнению со средними надоя и жвачки.
- **Evidence:** Мультипризнаковая animal model, AIREMLF90, 40 860 первотёлок, 168 стад, 18 047 505 суточных записей (Weller and Ezra, 2026, p. 6416, 6420–6422).
- **Уверенность:** 0,85 (очень большая выборка, малые SE наследуемостей, согласие с Elgersma et al., 2018 и Poppe et al., 2021; ограничение — одна популяция, только первотёлки).

**Claim 2:** Генетическая корреляция −LnVar молока (1–40 DIM) с кетозом = −0,62 — сильнейшая связь индикатора резилентности с болезнью.
- **Утверждение:** Более высокая дисперсия суточных надоев (низкая резилентность) генетически ассоциирована с более высокой инцидентностью кетоза; корреляция −0,623 (P < 0,05) — максимальная по модулю среди всех болезней (Weller and Ezra, 2026, p. 6422, Table 7).
- **Evidence:** Анализ 2 мультипризнаковой модели; значимые корреляции первой части лактации также для метрита (−0,312) и родового пареза (−0,353).
- **Уверенность:** 0,82 (большое n, значимость P < 0,05, согласие направления с Keßler et al., 2025 (0,36) и Elgersma et al., 2018 (−0,52); ограничение — наследуемость кетоза низкая, 0,051).

**Claim 3:** Первая часть лактации (1–40 DIM) информативнее остатка лактации для индикации резилентности.
- **Утверждение:** Значимые генетические корреляции с болезнями обнаружены преимущественно для функций 1–40 DIM; для 41–305 DIM ни одна из болезней не имела значимой корреляции с автокорреляцией обоих признаков, а единственная значимая корреляция с −LnVar (смещение сычуга, −0,362) относится к признаку с наследуемостью <0,01 (Weller and Ezra, 2026, p. 6421–6422).
- **Evidence:** Раздельный анализ периодов 1–40 и 41–305 DIM (Tables 7–8).
- **Уверенность:** 0,78 (консистентная картина по 5 болезням и 7 индексным признакам; ограничение — период 41–305 DIM более чем в 6 раз длиннее, что само по себе влияет на оценки).

**Claim 4:** Включение функций времени жвачки повышает точность предсказания племенных ценностей для всех анализированных признаков.
- **Утверждение:** При добавлении трёх функций RT (среднее, LnVar, автокорреляция за 1–40 DIM) к модели «BCS + функции молока» коэффициент детерминации вырос для всех 14 признаков как у коров, так и у быков; например, для задержания последа R² коров вырос с 0,346 до 0,482, для смещения сычуга — с 0,457 до 0,602 (Weller and Ezra, 2026, p. 6424, Table 9).
- **Evidence:** Множественная регрессия племенных ценностей (Equation [2]), 40 860 коров и 526 быков с ≥10 дочерьми.
- **Уверенность:** 0,80 (единообразный прирост по всем признакам; ограничение — R², а не валидация на независимой выборке).

**Claim 5:** Семь индикаторов резилентности за первые 40 DIM (плюс BCS) объясняют 18–19 % вариации племенной ценности по полному индексу PD20.
- **Утверждение:** R² для селекционного индекса: 0,182 (коровы, n = 35 929) и 0,187 (быки, n = 526); для пяти болезней R² коров >0,35, а для кетоза, смещения сычуга и родового пареза >0,6 (Weller and Ezra, 2026, p. 6416, 6422, Table 9).
- **Evidence:** Регрессия EBV на оценки индикаторных признаков; почти все коэффициенты резилентности значимы при P < 0,001 для коров.
- **Уверенность:** 0,72 (значимость высокая, но объяснённая дисперсия индекса умеренная; для быков большинство коэффициентов незначимы из-за n = 526).

**Claim 6:** Наследуемости индикаторов резилентности низкие, но достаточные для селекции.
- **Утверждение:** Наследуемости −LnVar: молоко 0,115 (1–40 DIM) и 0,179 (41–305 DIM); жвачка 0,054 и 0,168; автокорреляции 0,020–0,119; все SE < 0,016. По критериям Shook (1989) признак имеет генетическую вариацию, измеряется рутинно и дёшево (молоко) и доступен рано в жизни (Weller and Ezra, 2026, p. 6421, 6423, Table 5).
- **Evidence:** AIREMLF90 со стандартными ошибками; согласие с литературой (Elgersma et al., 2018: 0,10; Poppe et al., 2021: 0,12–0,15; Chen et al., 2024: 0,13).
- **Уверенность:** 0,83 (воспроизводимость в 4+ независимых популяциях; ограничение — низкие h² означают медленный прогресс при прямом отборе).

# 3. ВВЕДЕНИЕ

## 3.1. Контекст и значимость проблемы

Резилентность предложена как индикаторный признак здоровья и жизнеспособности (робастности) сельскохозяйственных животных. Упитанность (BCS) отражает энергетический баланс коровы и связана с резистентностью и толерантностью к болезням (Calus and Veerkamp, 2003; König and May, 2019; Bengtsson et al., 2022); Bengtsson et al. (2022) предложили использовать BCS как индикатор резилентности, а Weller and Ezra (2025) детально проанализировали этот признак у израильских голштинов. Альтернативный подход — анализ дисперсии и автокорреляции лонгитюдно регистрируемого признака, для молочного скота обычно суточного надоя. Исходное допущение: животное отвечает на возмущение изменением продуктивности; поскольку момент и наличие возмущения обычно неизвестны, анализируется не реакция на конкретное возмущение, а изменение признака во времени — низкая дисперсия указывает на высокую резилентность (Keßler et al., 2025, цит. по Weller and Ezra, 2026, p. 6416). Автокорреляция, близкая к нулю, интерпретируется как быстрое восстановление после возмущения (Berghof et al., 2019; Poppe et al., 2021; Friggens et al., 2022). Meijer et al. (2024) предложили включать индикаторные признаки резилентности в рутинную оценку племенной ценности (Weller and Ezra, 2026, p. 6416).

## 3.2. Обзор литературы (краткий)

1. **Keßler et al. (2025)** — селекционный индекс резилентности из двух дисперсионных индикаторов (немецкие голштины, 7 623 лактации); все корреляции с общей продуктивностью <0,5 (Weller and Ezra, 2026, p. 6417).
2. **Elgersma et al. (2018); Poppe et al. (2021); Wang et al. (2022)** — корреляции индикаторов резилентности с селекционными индексами и распространённостью болезней; более резилентные животные в среднем здоровее.
3. **Kok et al. (2021)** — пример различной чувствительности индикаторов: при мастите дисперсия суточных надоев выше, а автокорреляция ниже (Weller and Ezra, 2026, p. 6416–6417).
4. **Weller and Ezra (2024)** — генетические параметры времени жвачки (RT) по >30 млн суточных записей 77 000+ израильских голштинских коров; включение RT в индекс давало экономически положительные изменения прогресса по всем признакам, кроме жира и SCS (Weller and Ezra, 2026, p. 6417).

## 3.3. Гипотеза и цель исследования

**Цель:** оценить генетические и средовые корреляции между двумя индикаторами резилентности (−LnVar и автокорреляция суточного надоя и времени жвачки), BCS, средними надоя и жвачки, пятью метаболическими болезнями и семью признаками израильского индекса; дополнительно — оценить пригодность племенных ценностей индикаторов для предсказания племенных ценностей болезней, индексных признаков и полного индекса PD20. Периоды 1–40 DIM и 41–305 DIM анализировались раздельно из-за характерной формы кривых лактации обоих признаков (Weller and Ezra, 2026, p. 6417). Золотого стандарта выбора индикаторных признаков резилентности не существует: лежащее в основе возмущение обычно неизвестно, что затрудняет вывод экономических весов; один из подходов — анализ генетических корреляций индикаторов с признаками здоровья, продукции и продолжительности хозяйственной жизни (Weller and Ezra, 2026, p. 6416).

## 4.2. Данные и фильтры записей

- **Фильтры суточных записей:** удалены записи с RT <50 и >1 000 мин и надоем <5 и >100 кг.
- **Период 1–40 DIM:** лактации с ≥20 суточными записями, первой записью не позднее 10 DIM и последней не ранее 30 DIM.
- **Период 41–305 DIM:** лактации с ≥100 записями, первой не позднее 50 DIM и последней не ранее 200 DIM.
- **Фильтры коров:** валидные записи обоих периодов; записи по всем 5 болезням; BCS с −14 до +14 дней от отёла; возраст отёла 21–29 мес; отец — голштин. Сезоны: летние отёлы 1 апреля – 30 сентября, зимние — остальные месяцы.
- **Болезни:** задержание последа, метрит, кетоз, смещение сычуга, родовой парез; скоринг дихотомический (1 = зарегистрирована в первые 40 DIM, 0 = нет) по Weller et al. (2019). Частоты смещения сычуга и родового пареза <1 %.
- **BCS:** шкала 1,50–4,75 с шагом 0,25 (Weller and Ezra, 2025) (Weller and Ezra, 2026, p. 6417–6419).

## 4.3. Индексные признаки и модели анализа

Израильский индекс PD20 включает 9 признаков: молоко, жир, белок, SCS, женская фертильность, продолжительность хозяйственной жизни, персистентность, лёгкость отёла, выживаемость телят. Генетические корреляции для лёгкости отёла и выживаемости телят не вычислялись: лёгкость отёла включена как фиксированный эффект (трудный отёл — травматическое воздействие, прямо влияющее на резилентность); четыре уровня: лёгкий, трудный, без ассистенции (не наблюдался), хирургический. Наследуемости лёгкости отёла и выживаемости телят у первотёлок: 0,030 и 0,014 (Weller and Ezra, 2016) (Weller and Ezra, 2026, p. 6418).

Вычислено 7 мультипризнаковых анализов: анализ 1 — 12 признаков (средние, −LnVar, автокорреляции молока и RT в обоих периодах); анализы 2–4 — функции молока/RT + 5 болезней + BCS (по 10 признаков); анализы 5–7 — те же функции + 7 индексных признаков (по 11 признаков). Все модели включали фиксированные эффекты стадо-год-сезон и лёгкость отёла; анализы 1–4 — также возраст и месяц отёла (в анализах 5–7 индексные признаки предварительно скорректированы на эти факторы) (Weller and Ezra, 2026, p. 6419).

## 4.4. Вычисление функций резилентности и предсказание племенных ценностей

Суточные записи молока и RT анализировались PROC GLM (SAS) по модели T_ij = S_i + L_i + Q_i + N_i + e_ij, где S, L, Q, N — квадратный корень, линейный, квадратичный и обратный эффекты DIM. Анализируемые признаки — остатки (residuals) этой модели; ранее она показала лучшее соответствие для частичных лактаций, чем полиномы или классовые эффекты (Weller and Ezra, 2015, 2024). Для каждой частичной лактации вычислялись натуральный логарифм дисперсии остатков (LnVar) и автокорреляция первого порядка; анализировался −LnVar, поскольку низкая дисперсия ассоциируется с резилентностью (Keßler et al., 2025) (Weller and Ezra, 2026, p. 6419).

Модель предсказания (Equation [2]): EBV_i = a×BCS + b×MM + c×MR + d×VM + f×VR + g×AM + h×AR + e, где MM/MR — средние молока и RT 1–40 DIM, VM/VR — LnVar молока и RT, AM/AR — автокорреляции. Модель вычислялась также без функций RT для оценки их добавленной объяснительной силы. Те же модели применялись к быкам с ≥10 дочерьми (n = 526). Для болезней и BCS использовались решения моделей 2 и 5; для индексных признаков — племенные ценности официальной оценки октября 2025 г. (Weller and Ezra, 2026, p. 6420).

## 6.3. Механистические выводы

1. **Дисперсионный индикатор специфичен к устойчивости, а не к уровню продукции:** для болезней максимальный вклад вносят −LnVar и автокорреляции, а не средние (Weller and Ezra, 2026, p. 6422).
2. **Ранняя лактация — критическое окно:** значимые связи с метаболическими болезнями сосредоточены в 1–40 DIM, что соответствует периоду максимальной заболеваемости (Weller and Ezra, 2026, p. 6421–6422).
3. **Антагонизм резилентности и продукции у молока:** отрицательные корреляции надоя с −LnVar означают, что отбор на стабильность без индексного взвешивания снизил бы прогресс по продукции (Weller and Ezra, 2026, p. 6423).
4. **Жвачка несёт добавочную информацию:** функции RT повышали R² для всех 14 признаков у обоих полов, хотя сами не имели значимых корреляций с индексными признаками (Weller and Ezra, 2026, p. 6424). Современные индексы могут иметь отрицательный генетический тренд по резилентности; добавление веса на BCS и LnVar способно его обратить (Bengtsson et al., 2022, цит. по Weller and Ezra, 2026, p. 6423).

## 7.1. Сильные стороны

- **Масштаб данных:** 18 млн суточных записей, 40 860 первотёлок, 168 стад — на порядки больше большинства предшествующих работ (Weller and Ezra, 2026, p. 6417).
- **Раздельный анализ 1–40 и 41–305 DIM:** учитывает форму кривых лактации и выявляет информативность раннего периода — методологическое улучшение относительно триместрового деления Poppe et al. (2021).
- **Отрицательный контроль и полная диагностика:** средние молока и RT включены как предикторы-контроли (эффект вариабельности отделён от уровня); стандартные ошибки всех оценок (AIREMLF90 после MTC), полная матрица корреляций 12 функций и эксплицитная проверка по критериям Shook (1989) (Weller and Ezra, 2026, p. 6422–6423).

## 7.2. Ограничения

**Внутренние:**
- **Только первотёлки и одна популяция** (израильские голштины); хозяйственная жизнь в основном «ожидаемая» — большинство коров ещё не завершили жизнь, анализ основан на ожидаемой продолжительности (Weller and Ezra, 2015) (Weller and Ezra, 2026, p. 6418).
- **Низкие наследуемости трёх болезней** (задержание последа 0,006, смещение сычуга 0,007, родовой парез 0,002) и их низкие частоты (<1 % для двух) ограничивают интерпретируемость соответствующих корреляций (Weller and Ezra, 2026, p. 6418, 6421).
- **R² — это in-sample детерминация,** а не точность геномного предсказания на независимой валидации; для быков n = 526 и большинство коэффициентов незначимы [интерполяция].
- **Возмущения не наблюдались напрямую:** дисперсия и автокорреляция — косвенные маркеры; «золотого стандарта» резилентности нет (Weller and Ezra, 2026, p. 6416).

**Внешние:**
- **Зависимость от инфраструктуры:** выводы привязаны к системе SCR и израильской системе регистрации болезней; частота метрита 45 % указывает на иные пороги регистрации, чем в других странах [интерполяция].

## 8.2. Ключевые выводы (структурировано)

1. **Лучший индикатор резилентности — −LnVar суточного надоя за 1–40 DIM** (h² = 0,115): генетически связан со всеми пятью метаболическими болезнями, BCS и всеми семью индексными признаками.
2. **Сильнейшая связь — с кетозом (−0,62):** генетически вариабельный надой в ранней лактации маркирует предрасположенность к кетозу.
3. **Ранняя лактация информативнее:** в 41–305 DIM значимых связей болезней с автокорреляциями нет.
4. **Жвачка усиливает предсказание:** функции RT повышают R² всех 14 признаков, включая болезни (например, задержание последа 0,346 → 0,482).
5. **Индексное включение обосновано:** R² = 0,18–0,19 для PD20 по ранним индикаторам; признак доступен рано в жизни и дёшев (молоко регистрируется рутинно).

## 8.3. Ключевые сообщения для лекции

1. Резилентность измерима без наблюдения самих возмущений: дисперсия и автокорреляция суточных записей — наследуемые индикаторы (h² ≈ 0,11 для LnVar надоя).
2. Первые 40 дней лактации — диагностическое окно: именно там сосредоточены генетические связи индикаторов с метаболическими болезнями.
3. Двойственность дисперсии надоя: низкая вариабельность генетически связана и со здоровьем, и с меньшей продуктивностью — поэтому резилентность включают в индекс с весом, а не отбирают изолированно.
4. Сенсорные данные (жвачка) дают добавочную предиктивную силу поверх молока и BCS для всех признаков, включая болезни с наследуемостью <0,01.
5. Критерии Shook (1989) для нового признака селекции: экономическая ценность, генетическая вариация, дешёвое рутинное измерение — индикаторам резилентности по суточному молоку они удовлетворяют.

# 9. FAQ

**Вопрос 1: Что такое резилентность и как её измерить у коровы?**
Ответ: Резилентность — способность сохранять продуктивность или быстро восстанавливаться после возмущения. Поскольку сами возмущения обычно неизвестны, измеряют вариабельность лонгитюдного признака: низкая дисперсия суточных надоев (высокий −LnVar) указывает на высокую резилентность, а автокорреляция, близкая к нулю, — на быстрое восстановление (Keßler et al., 2025; Berghof et al., 2019; цит. по Weller and Ezra, 2026, p. 6416).

**Вопрос 2: Какой индикатор резилентности лучший и почему?**
Ответ: −LnVar суточного надоя за первые 40 DIM: наследуемость 0,115, максимальные по модулю генетические корреляции с болезнями (кетоз −0,62) и лучшие предиктивные свойства среди тестированных. Для болезней −LnVar молока был лучшим индикатором, чем средний надой или функции жвачки (Weller and Ezra, 2026, p. 6416, 6422).

**Вопрос 3: Почему анализировали первые 40 дней отдельно от остатка лактации?**
Ответ: Из-за формы кривых: надой и жвачка быстро растут до ~40 DIM и достигают пика к 75–90 DIM; смешение фаз роста и плато исказило бы дисперсии. Кроме того, именно первые 40 DIM — период максимальной частоты метаболических болезней, и генетические корреляции с болезнями сосредоточены в этом окне (Weller and Ezra, 2026, p. 6417, 6421–6422).

**Вопрос 4: Даёт ли мониторинг жвачки что-то сверх надоев?**
Ответ: Да. Хотя индексные признаки не имели значимых генетических корреляций с функциями RT, включение трёх функций жвачки в регрессионную модель повышало R² для всех 14 признаков у коров и быков — например, для смещения сычуга с 0,457 до 0,602, для задержания последа с 0,346 до 0,482 (Weller and Ezra, 2026, p. 6422, 6424, Table 9).

**Вопрос 5: Насколько хорошо ранние индикаторы предсказывают племенную ценность и не замедлит ли отбор рост надоев?**
Ответ: Для полного индекса PD20 — R² 0,182 (коровы) и 0,187 (быки); для болезней у коров R² >0,35, для кетоза — 0,676. Потенциальный антагонизм с продукцией существует: генетическая корреляция надоя с −LnVar молока отрицательна (−0,66…−0,84), поэтому авторы предлагают включать индикатор в индекс с экономическим весом, а не отбирать по нему изолированно (Weller and Ezra, 2026, p. 6416, 6423–6424; [интерполяция]).

# 10. ПРАКТИЧЕСКОЕ ПРИМЕНЕНИЕ

## 10.1. Алгоритм внедрения индикатора резилентности

1. **Обеспечить суточную регистрацию надоев** с отёла до ≥30 DIM (минимум 20 валидных записей, первая ≤10 DIM) — требования к полноте данных из фильтров статьи (Weller and Ezra, 2026, p. 6417).
2. **Скорректировать суточные записи на DIM** моделью с квадратным корнем, линейным, квадратичным и обратным эффектами дня лактации; работать с остатками, а не сырыми надоями.
3. **Вычислить −LnVar и автокорреляцию остатков** за 1–40 DIM для каждой коровы; при наличии сенсоров жвачки — те же функции для RT.
4. **Оценивать племенные ценности** мультипризнаковой animal model с эффектами стадо-год-сезон и лёгкость отёла (трудный отёл — фиксированный эффект, травматический фактор); включать индикатор в индекс с весом, а не отбирать изолированно — из-за антагонизма с уровнем надоя (Weller and Ezra, 2026, p. 6419, 6423).

## 10.2. Типичные ошибки

- **Анализ сырых надоев без коррекции на DIM и смешение ранней и поздней лактации:** форма кривой лактации сама создаёт дисперсию, не связанную с резилентностью, а усреднение по всей лактации размывает сигнал первых 40 DIM (Weller and Ezra, 2026, p. 6419).
- **Отбор на низкую дисперсию без индексного взвешивания** приведёт к коррелированному снижению надоя; **интерпретация корреляций болезней с h² <0,01 как доказательных** недопустима — для задержания последа, смещения сычуга и родового пареза оценки ненадёжны (Weller and Ezra, 2026, p. 6421).
- **Пренебрежение лёгкостью отёла как фиксированным эффектом:** трудный отёл — травма, напрямую влияющая на резилентность коровы (Weller and Ezra, 2026, p. 6418).

## 10.3. Пограничные сценарии

- **Хозяйства без сенсоров жвачки:** рабочий вариант — только функции молока + BCS (модель «BCS+молоко» в Table 9 сохраняет R² 0,35–0,66 для болезней у коров) [интерполяция из Table 9].
- **Коровы поздних паритетов и низкопродуктивные стада:** статья охватывает только первотёлок со средним надоем 34 кг/сут; Keßler et al. (2025) анализировали паритеты 1–6 с меньшими корреляциями (кетоз 0,36), а при надоях на 25 % ниже (Poppe et al., 2021) −LnVar вдвое меньше — перенос требует осторожности (Weller and Ezra, 2026, p. 6420, 6422).
- **Геномная оценка молодых животных без записей:** надёжности геномных EBV сейчас выше педигрейных даже для признаков с низкой наследуемостью — это усиливает аргумент за ранние индикаторы (Guinan et al., 2023; Curzon et al., 2024, цит. по Weller and Ezra, 2026, p. 6424).
