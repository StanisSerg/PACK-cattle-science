# CS.SOTA.396 — Выживаемость симменталов по паритетам (Animal 2024)

## Ключевое для практики

- Анализ выживаемости (SURV) итальянских симменталов двойного назначения по паритетам; данные 2 173 первотёлок официального учёта; метод — анализ выживаемости (Kaplan-Meier).
- Сохранность зависит от сезона первого отёла, продуктивности и морфологии.
- Контекст: симменталы как порода двойного назначения historically держатся в стаде дольше голштинов (сравнение: продуктивная жизнь голштин ~2.5–3 лактации — CS.SOTA.024 De Vries 2017, темп выбытия ~36%/год).
- Применение для нас (Ж/К Ленинский): шкала сравнения темпа выбытия для симментальского стада; прямой породный референс вместо голштинского.
