# B-03.D-03 — Операционная инструкция: учетчик кормов МТФ Плянта (ОАО «Остромичи»)

> Роль: **учетчик кормов МТФ Плянта — Ромаш Валентина Николаевна** (поправка пилота 2026-08-03: роль кормления на Плянте несёт учетчик кормов, не гл. зоотехник).
> **Площадка: ферма Плянта — пилотная.** Здесь отрабатываем подход; масштабирование — после приёмки пилота.
> Ядро роли: **контроль внедрения и применения рационов, выданных консультантом** — через загрузочные листы и учёт.
> Действующая запись, на которую опирается инструкция: **загрузочные листы Плянты** + кормовые документы учетчика.
> Принцип: каждая операция имеет проверяемую запись. Нет записи — операция не считается выполненной.

## 1. Ежедневно

| # | Операция | Проверяемая запись |
|---|----------|--------------------|
| 1.1 | Выписать/обновить загрузочный лист на день по действующему рациону (группы, компоненты, количество) | Загрузочный лист дня |
| 1.2 | Сверить фактическую загрузку миксера с загрузочным листом (компоненты, количество, порядок загрузки) | Отметка на загрузочном листе; отклонения зафиксированы с причиной |
| 1.3 | Учесть поступление и расход кормов за день | Записи учёта (кормовые документы) |
| 1.4 | Зафиксировать отклонения дня (перерасход, недокорм, замены компонентов) и причины | Запись дня на листе |

## 2. Еженедельно

| # | Операция | Проверяемая запись |
|---|----------|--------------------|
| 2.1 | Сверить фактический расход кормов с рационом | Недельная сводка расхода |
| 2.2 | Сверить остатки: склад концентратов, траншеи (выемка) | Запись сверки остатков |
| 2.3 | Скорректировать загрузочные листы под текущие группы и остатки | Обновлённые листы с датой |

## 3. По событиям

| Событие | Действия учетчика кормов | Проверяемая запись |
|---------|--------------------------|--------------------|
| Получен новый рацион от консультанта | В течение 1 рабочего дня перевести рацион в загрузочные листы | Лист с датой внедрения |
| Первая неделя внедрения рациона | Ежедневная сверка загрузки с новым листом (п. 1.2) + фиксация отклонений | Ежедневные записи недели внедрения |
| Изменение технологических групп | Обновить загрузочный лист до первой выдачи корма новой группе | Обновлённый лист |
| Отклонение по корму (качество, срыв поставки) | Передать информацию гл. зоотехнику/консультанту, зафиксировать согласованную замену | Запись о замене с обоснованием |

## 4. Месяц

| # | Операция | Проверяемая запись |
|---|----------|--------------------|
| 4.1 | Свод по отклонениям месяца: причины, повторяемость, меры | Месячная сводка для директора |
| 4.2 | Данные для оценки KPI (см. `B-03.D-04`) | Записи месяца, доступные директору без расспросов |

## Открытые пробелы (закрыть до v1.0)

1. **Состав рабочего дня по факту** — сверить с реальным днём Ромаш В.Н. (наблюдение/интервью): что добавить, что лишнее. В частности: проверяет ли она кормовой стол физически или только бумажный контур.
2. **Форма загрузочного листа Плянты** — посмотреть действующий бланк: инструкция должна опираться на реальные графы, а не на выдуманные.
3. **Пороги отклонений** (п. 1.2): какое отклонение по компоненту считается допустимым — решение пилота/консультанта.
4. **Форма месячной сводки** (п. 4.1): достаточно ли таблицы «отклонение — причина — мера».

## Масштабирование (после приёмки пилота на Плянте)

- Подберье — есть TMR-трекер: инструкция адаптируется под электронную запись.
- Шляхта, Борки, Жуховцы — носитель неизвестен: сначала выяснить, что там с записями.
