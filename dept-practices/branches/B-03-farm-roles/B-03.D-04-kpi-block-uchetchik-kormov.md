# B-03.D-04 — KPI-блок: учетчик кормов МТФ Плянта (Ромаш В.Н.)

> Предложение-замена существующего блока в `dept-practices/personal-bonus-kpi-all-staff.md` (раздел 2, Ромаш Валентина Николаевна — учетчик кормов МТФ Плянта).
> Принцип модели: наблюдаемые KPI, оценка 0 / 25 / 50 / 75 / 100%, итог = среднее.
> **Пилотная площадка: ферма Плянта** — источник наблюдений: загрузочные листы Плянты + кормовые документы.
> Опора: записи операционной инструкции `B-03.D-03` — оценка ставится по записям, без расспросов.

## Зачем замена, а не добавление

Действующий блок Ромаш В.Н. в модели:
1. Точность учёта поступления и расхода кормов.
2. Своевременность оформления кормовых документов.
3. Соответствие фактического расхода кормов нормам (без критичных перерасходов).
4. Порядок в складском учёте кормов.

Это KPI **учёта**. Ядро работы по ветви B-03 — **внедрение и применение рациона** (загрузочные листы, сверка загрузки, отклонения). Директору «непонятно, за что премировать» именно потому, что блок не меряет эту работу. Предлагаемый блок объединяет оба контура без раздувания до 8 KPI.

## Предлагаемый блок (4 KPI)

| # | KPI | Источник наблюдения | Что сохранено из старого блока |
|---|-----|--------------------|-------------------------------|
| K1 | **Соответствие загрузки рациону:** фактическая загрузка миксера соответствует загрузочному листу, отклонения только с зафиксированной причиной | Загрузочные листы Плянты (отметки п. 1.2 инструкции) | Поглощает старое №3 (расход по нормам) |
| K2 | **Своевременность внедрения рационов консультанта:** новый рацион переведён в загрузочные листы в течение 1 рабочего дня | Дата рациона vs дата внедрения в листах | Новый (ядро B-03) |
| K3 | **Точность учёта:** поступление и расход кормов учтены без ошибок и пересортировки | Кормовые документы, сверки остатков | Старые №1 и №4 объединены |
| K4 | **Полнота записей:** загрузочные листы дня, недельная сводка расхода, месячная сводка отклонений — без пропусков и «задним числом» | Записи `B-03.D-03` пп. 1.1–1.4, 2.1, 4.1 | Поглощает старое №2 (документы в срок) |

Оценка по каждому: 0 / 25 / 50 / 75 / 100 — по общим правилам модели; итог = среднее по 4.
