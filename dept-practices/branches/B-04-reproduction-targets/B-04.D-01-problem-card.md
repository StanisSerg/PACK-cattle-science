# B-04.D-01 — Карточка проблемы: нет зафиксированных целевых показателей воспроизводства в ОАО «Остромичи»

> Паттерн: `C.22.2` (ProblemCard@Context). Карточка — эпистема о проблемной стороне, не сама проблема и не метод.
> Источник сигнала: WP-113 (зарегистрирован 2026-08-10 по команде пилота); решение о выделении в отдельную ветвь Звена 2 — пилот, 2026-08-20.

## Наблюдаемый сигнал

В ОАО «Остромичи» нет зафиксированных целевых значений показателей воспроизводства. Без них:

- невозможно оценить текущее состояние стада (отклонение от нормы) — «выше/ниже цели» сказать не по чему;
- невозможно построить KPI роли, отвечающей за воспроизводство (по образцу D-04 ветви B-03);
- не измеряется эффект от внедрения методов ветви LPF.

Форма проблемы та же, что в B-03 (D-01): показатели «есть у всех в голове», но не переведены в передаваемое описание.

## Bounded context

ОАО «Остромичи»; пилотная площадка — ферма Плянта (по аналогии с B-03). Учётная система хозяйства для осеменений/отёлов не зафиксирована (открытый вопрос — определяет точки измерения).

## Интересующая сущность (EntityOfConcern)

Передаваемый набор целевых показателей воспроизводства стада: перечень метрик + целевое значение + источник норматива + точка измерения. Не репродуктивная программа как таковая (это методы хозяйства), не KPI-модель персонала (это D-04 ветви B-03).

## Критерий готовности ветви (первый неподтверждённый результат)

Пилот может по документу показателей сказать по каждому: «выше/ниже цели» для Остромичей, не открывая других источников (критерий готовности WP-113).

## Связи

- WP-113 — РП, в рамках которого собран первый документ ветви (B-04.D-02).
- B-03 — соседняя ветвь Звена 2 (роли хозяйства): показатели — вход для KPI роли воспроизводства по образцу D-04.
- WP-97 (лекция 5.2) — источник набора метрик; SoTA PACK (CS.SOTA.001, 005, 013, 015) — источники нормативов.
