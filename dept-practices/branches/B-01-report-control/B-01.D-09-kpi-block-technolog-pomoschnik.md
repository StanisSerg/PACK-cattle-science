# B-01.D-09 — KPI-блок: технолог-помощник отдела (метод «замер и внесение данных»)

> **Граница действия:** блок **не действует как инструмент оценки до конца первого месяца пилота** — пороги 75/50/25% не откалиброваны. В период пилота блок работает только как дисциплина наблюдения (ведущий ведёт ревизии, возвраты = обучение).
> Опора: записи операционной инструкции `B-01.D-08` — оценка ставится по записям (md-таблицы кейсов, АМТС), без расспросов.
> Принцип модели (как в `personal-bonus-kpi-all-staff.md` / B-03.D-04): наблюдаемые KPI, оценка 0 / 25 / 50 / 75 / 100%, итог = среднее.
> Пилот метода: 2 технолога-помощника + ведущий; после утверждения — весь отдел (8 человек).

## Зачем блок

Метод (D-07) и инструкция (D-08) без измерения использования — мёртвый протокол (SoTA-пара «чек-лист эффект/не-эффект»). Блок отвечает на вопрос «работает ли стандарт» по записям, а не по самоотчётам, и закрывает приёмочную пробу карточки `B-01.D-06`: 4 недели без возвратов на переделку.

## Предлагаемый блок (4 KPI)

| # | KPI | Источник наблюдения |
|---|-----|--------------------|
| K1 | **Полнота базового набора:** все 5 показателей (СВ, Пенсильванские сита, жвачка, молоко, реализация) внесены в md-таблицу в каждом визите; пропуск = только оформленный неполный замер | md-таблицы кейсов хозяйств |
| K2 | **Своевременность в момент визита:** строка визита в md-таблице + сита/СВ в АМТС + сохранённая корректировка — до отъезда (2a) | Даты записей vs даты визитов |
| K3 | **Дисциплина переменного набора:** по каждому из 6 переменных показателей есть отметка «выполнен» или «не требовался по правилу» — неявных пропусков нет | Отметки в md-таблицах |
| K4 | **Качество записей:** записи приняты ведущим без возвратов на доработку | Ревизии ведущего (см. ниже) |

Оценка по каждому: 0 / 25 / 50 / 75 / 100 — по общим правилам модели; итог = среднее по 4.

## Порядок ревизии записей ведущим (закрывает пробел D-08 §5)

- Выборочная ревизия: **[ВОПРОС ПИЛОТУ]** — кандидат: 2 последние записи каждого технолога раз в 2 недели в период пилота; после утверждения — 1 запись в месяц.
- Возврат на доработку — с формулировкой, чего не хватает (не «переделай»); возврат учитывается в K4.
- Ревизия — не карательная: первые 4 недели (приёмочная проба) возвраты = обучение, в K4 не идут. **[ВОПРОС ПИЛОТУ — принять ли такую амнистию пилота]**

## Открытые пробелы

1. Пороги 75/50/25% по каждому KPI — калибровка на первом месяце пилота (базовая линия).
2. Частота ревизий и амнистия пилота — решения пилота (выше).
3. Связка блока с действующей моделью премирования отдела (`personal-bonus-kpi-all-staff.md`) — отдельное решение после приёмки пилота метода.
