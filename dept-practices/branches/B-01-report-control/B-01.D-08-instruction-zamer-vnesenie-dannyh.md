# B-01.D-08 — Операционная инструкция: замер и внесение данных при посещении хозяйства (технолог отдела)

> Описание-редакция v0.2 метода `B-01.D-07` (заявление утверждено пилотом 2026-08-28).
> Адресат: **технолог-помощник технологического отдела** — для работы в любом хозяйстве на сопровождении.
> Принцип: каждая операция имеет проверяемую запись. Нет записи — операция не считается выполненной.
> **Поток данных (уточнение пилота 2026-08-28):** все данные замера вносятся **сначала в md-таблицы** кейса хозяйства (формат — по образцу `DS-cattle-cases/cases/CASE-002-zencht-leninsky-dynamics/raw/milk_dynamics_Len_2026-05.md`); в **АМТС** дублируется только часть показателей (сита, СВ) — она нужна для корректировки рациона.
> Инструкция **заменяет** записные книжки, точечные сообщения в Telegram и сводные таблицы по запросу — не добавляется к ним.

## 1. Чек-лист визита — до отъезда (2a)

Пункты — контрольные вопросы о состоянии объектов (да/нет). Все «нет» → раздел 4 (неполный замер).

| # | Контрольный вопрос | Проверяемая запись |
|---|--------------------|--------------------|
| 1.1 | Замер базового набора выполнен: СВ, Пенсильванские сита, жвачка, молоко из компьютера, реализация из журнала — значения внесены в md-таблицу хозяйства? | Строка визита в md-таблице кейса |
| 1.2 | Переменный набор: по каждому показателю отмечено «выполнен» или «не требовался по правилу» (раздел 2)? | Отметки в md-таблице |
| 1.3 | Сита и СВ продублированы в АМТС, корректировка в рамках основного рациона выполнена и сохранена? (нельзя скорректировать рацион без внесённых данных — внесение подразумевается) | Сохранённый рацион в АМТС |
| 1.4 | Выход за рамки основного рациона? → эскалация ведущему технологу (ветвление A), сам не корректирую | Запись эскалации (дата, суть, кому) |
| 1.5 | Корректировка согласована с зоотехником хозяйства? Не согласована → возврат к корректировке (ветвление B) | Отметка о согласовании |

## 3. Неделя — после визита (2b)

> **[ВОПРОС ПИЛОТУ]:** данные теперь уходят в md-таблицу в момент визита (§1) — сохраняется ли недельный хвост 2b (например, анализ/примечания по кейсу) или вся фиксация закрывается в день визита?

## 4. Процедура неполного замера

1. Стоп: не «дописывать по памяти».
2. Зафиксировать в md-таблице кейса: «неполный замер» — что именно не выполнено и почему (нет доступа к компьютеру/журналу, АМТС недоступна и т.п.).
3. Уведомить ведущего технолога **в тот же день** (канал — по правилам отдела).
4. Данные неполного замера не используются в сравнении хозяйств — отметка в записи.

## 5. Критерий приёмки визита

Визит считается выполненным по методу, если:
- пп. 1.1–1.3 закрыты (или оформлен неполный замер по разделу 4);
- оформление записи кейса завершено до конца недели (п. 3.1);
- эскалации/возвраты оформлены записями (пп. 1.4–1.5).

Владелец сравнения: ведущий технолог — выборочная ревизия записей (порядок ревизии — в KPI-блоке D-09).

## Формат таблиц данных

Шаблоны не создаём с нуля — формат уже отработан в кейсах: шапка «Параметры измерения» (ферма, источник данных) + таблица с датами по строкам и показателями по столбцам. Образец: `DS-cattle-cases/cases/CASE-002-zencht-leninsky-dynamics/raw/milk_dynamics_Len_2026-05.md`. Для базового и переменного наборов — таблицы по этому же образцу в кейсе каждого хозяйства.

**Локус кейсов хозяйств:** кандидат — `DS-cattle-cases/cases/CASE-NNN-<slug>/raw/` (там уже живут кейсы; создание нового кейса — только через `bash DS-cattle-cases/scripts/case-new.sh CASE-NNN farm-slug`, правило репо). Правило «если кейса хозяйства ещё нет» → ведущий создаёт кейс до первого визита по методу. **[ВОПРОС ПИЛОТУ — подтвердить локус]**

## Открытые пробелы (закрыть до v1.0)

1. **Триггеры и периодичности переменного набора** (раздел 2) — решение пилота.
2. **Сохраняется ли 2b** (раздел 3) — уточнение пилота.

4. **Порядок ревизии записей ведущим** (раздел 5) — вместе с KPI-блоком D-09.
5. **Состав md-таблиц под базовый и переменный наборы** — создать по образцу CASE-002 на первом пробном визите.

**Примечание к внедрению (SoTA-пара «чек-лист эффект/не-эффект» — Urbach 2014, NEJM: мандат чек-листов в Онтарио дал ноль эффекта; Haynes 2009, NEJM: чек-лист ВОЗ снизил смертность 1,5→0,8%; вывод Leape: изменение практики — социальная проблема поведения, не техническая проблема галочек):** форма без внедрения не работает. Внедрение = обучение (лесенка допуска из D-07 §7: сопровождаемый визит → самостоятельный под ревизию → допуск) + контроль использования первые 4 недели (приёмочная проба карточки D-06).
