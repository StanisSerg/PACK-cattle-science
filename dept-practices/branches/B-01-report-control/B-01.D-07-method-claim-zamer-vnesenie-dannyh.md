# B-01.D-07: Заявление метода «Замер и внесение данных при посещении хозяйства» (стандарт отдела)

> Заявление по A.3.1 (U.Method): фиксация переиспользуемого способа действия при заявленной применимости.
> Опора: эскиз из `B-01.D-02` (практика 4, подтверждён пилотом 01.08) + сверка пробелов `B-01.D-04`.
> Рамка: метод технологического **отдела** для работы с хозяйствами в целом (решение пилота 2026-08-28).
> Три независимости выдержаны: без имён людей, без конкретных визитов, без документов-описаний.

## 1. Имя метода

**«Замер и внесение данных при посещении хозяйства»** — единый стандарт фиксации результатов посещения для технологов отдела. Заменяет разрозненные практики (записные книжки, точечный Telegram, сводные таблицы по запросу), а не добавляется к ним.

## 2. Забота метода (method concern, явно)

**Наблюдать** состояние кормления и стада (замер), **изменять** рацион в день визита (в рамках основного), **сохранять** сопоставимые между хозяйствами данные посещений в приёмниках отдела.

## 3. Применимость

- Хозяйства на сопровождении отдела с визитами технолога (ритм: раз в неделю; индивидуально 2/нед – 1/2 нед).
- Корректировки — в рамках основного рациона ведущего технолога.
- Пределы: метод не покрывает методику самого контрольного доения на ферме, расчёт основного рациона, план обучения (отдельный план работ).

### 3.1. Состав замера: базовый + переменный набор

Состав показателей визита **не фиксирован целиком** — метод задаёт два набора и правило вариации:

- **Базовый набор (каждый визит, обязателен):** обеспечивает сопоставимость между хозяйствами — СВ, Пенсильванские сита, жвачка, молоко из компьютера, реализация из журнала *(утверждено пилотом 2026-08-28)*.
- **Переменный набор (по показаниям или расписанию):** навозные сита, pH мочи, BCS, размеры стойл и комфорт коров, скорость движения воздуха, оценка распорядка дня коровы *(наполнение утверждено пилотом 2026-08-28; триггеры и периодичность каждого — правила вариации в описании D-08)*.

Правило: технолог не волен пропускать базовый набор; переменный — выполняется по правилам D-08 и фиксируется в записи визита явно (выполнен / не требовался по правилу X).

## 4. Предусловия

- Основной рацион существует (ведущий технолог).
- АМТС доступна на месте.
- Описания метода опубликованы (чек-лист визита, markdown-шаблон замера — D-08).

## 5. Эффекты / постусловия

- Данные замера внесены в md-таблицу кейса хозяйства; сита и СВ продублированы в АМТС, рацион скорректирован и сохранён — **до отъезда** (2a). *(Поток уточнён пилотом 2026-08-28: первичный приёмник — md-таблицы; в АМТС — только часть показателей для корректировки.)*
- Оформление записи визита в кейсе завершено — **до конца недели** (2b, под вопросом пилота — см. D-08 §3).
- Цепочка «замер → данные → корректировка → внедрение» замыкается без ведущего технолога в рутине.
- Данные сопоставимы между хозяйствами (одинаковый набор показателей) → работает контроль отчётов и сравнение хозяйств.

## 6. Роды участников (generic participant meanings)

| Род | Роль в методе |
|---|---|
| Технолог-помощник отдела | Исполнитель: замер, запись в md-таблицу, дублирование сит/СВ в АМТС, корректировка в рамках допуска |
| Ведущий технолог отдела | Владелец основного рациона; эскалация при выходе за рамки; ревизия метода и записей |
| Зоотехник хозяйства | Согласование внедрения корректировки |
| md-таблицы кейса хозяйства | Первичный приёмник данных замера; аналитика агентами и отчёты; формат — по образцу CASE-002 |
| АМТС (программа расчёта рациона) | Приёмник части показателей (сита, СВ) для корректировки рациона — в момент визита |

## 7. Условия приёмки по способностям (A.2.2, пороги допуска к методу)

Технолог-помощник допускается к самостоятельному выполнению метода, если умеет:
1. отбирать и оценивать пробы: СВ (сухое вещество), Пенсильванские сита, навозные сита;
2. оценивать жвачку и считывать данные молока из компьютера, реализацию из журнала;
3. замерять pH мочи;
4. оценивать BCS (бальная оценка упитанности);
5. замерять размеры стойл и оценивать комфорт коров;
6. оценивать скорость движения воздуха;
7. знать оптимальный «распорядок дня коровы» и оценивать фактический на соответствие;
8. вносить данные в АМТС и сохранять корректировку рациона;
9. заполнять markdown-шаблон замера.

Проверка порога: сопровождаемый визит с ведущим технологом → самостоятельный визит под ревизию записей → допуск.

## 8. Условия отказа и остановки

- **Ближайшая остановка:** АМТС недоступна или данные неполные → стоп, markdown-фиксация «неполный замер», уведомление ведущего в тот же день.
- **Ветвление A (эскалация):** выход за рамки основного рациона → не корректировать, эскалация ведущему.
- **Ветвление B (возврат):** корректировка не согласована зоотехником → возврат к корректировке.
- Описание перестало соответствовать методу (сменился состав показателей, приёмники, ритм) → ревизия описания ведущим, запрет использования старой редакции.

## 9. Принадлежность описаний

Один метод — несколько описаний (A.3.2), все ссылаются на это заявление:
- **D-08** — операционная инструкция (чек-лист визита + правило 2a/2b + процедура неполного замера + критерий приёмки визита);
- markdown-шаблон замера (в составе D-08 или отдельным описанием — решение автора при написании).

## 10. Отношение к работе

- Конкретный визит — датированная работа (A.15.1): запись о визите ссылается на редакцию описания, по которой работал технолог.
- Пилот метода (2 помощника + ведущий, 4 недели) и обучение отдела (8 человек) — план работ (A.15.2), не часть метода.
- Договорённости с конкретными технологами — назначения ролей (A.2/A.15), в методе остаются только роды и пороги.
