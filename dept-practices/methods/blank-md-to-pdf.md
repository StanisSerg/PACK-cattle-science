# Изготовление печатного бланка для хозяйства (md → PDF)

> Описание метода (FPF A.3.2): как из markdown получить печатный бланк A4,
> который технолог хозяйства заполняет от руки в точке работы.

## Когда применять

Нужен рабочий документ (бланк замера, анкета, чек-лист) для роли хозяйства —
ветви B-01/B-03/B-04. Пригодится при масштабировании на другие роли и фермы.

## Предусловия

- venv с weasyprint: `.tmp-tools/markitdown-venv` (в workspace IWE).
- Скрипт `.tmp-tools/md2pdf-blank.py` (вход: md, выход: PDF A4).
- Исходник бланка — markdown-файл на диске.

## Параметры (критичные для заполнения от руки)

- Шрифт DejaVu, текст 9.5pt.
- **Строки таблиц ≥ 9 мм** — иначе не вписать значения ручкой.
- Реквизиты — отдельными строками (жёсткий перенос двумя пробелами в md).

## Шаги

1. Отредактировать md-исходник бланка.
2. **Перед пересборкой перечитать md с диска** — пилот правит бланки
   в Obsidian между итерациями; сборка из кэша/памяти теряет его правки.
3. Собрать PDF: `md2pdf-blank.py <бланк>.md` → `<бланк>.pdf` (A4).
4. Проверить PDF глазами: высота строк таблиц, переносы реквизитов,
   помещается ли в 1–2 страницы.

## Семантика отказа

- weasyprint недоступен / venv не активирован → метод не применяется,
  не подменять другими конвертерами без проверки высоты строк.
- PDF собран, но строки < 9 мм → итерация по параметрам, не сдавать бланк.

## Условия оценки результата

Бланк принят, если технолог хозяйства может заполнить его ручкой в точке
работы без пояснений автора (проверка — на реальном заполнении, ветвь B-03).
