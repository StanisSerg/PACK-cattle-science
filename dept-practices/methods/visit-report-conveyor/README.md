# Конвейер «посещение → отчёт»

Связка из 4 скиллов для полного цикла обработки посещения хозяйства:
транскрипция → карта посещения → технологический отчёт → независимое ревью → итерации → финал на экспертную правку технологу.

## Скиллы (установлены в `.claude/skills/`)

| Скилл | Стадия | Вход → Выход |
|-------|--------|--------------|
| `agro-orchestrator` | Управление циклом | Любая точка входа → весь конвейер; сам ничего не пишет, управляет стадиями, версиями, изоляцией ролей |
| `agro-visit-transcript` | Карта | Транскрипция (Plaud и т.п.) → Карта посещения с уровнями достоверности |
| `agro-technologist-report` | Отчёт | Карта/реестр + данные → технологический отчёт «факт → интерпретация → решение → контроль» |
| `agro-report-review` | Ревью | Пара «якорь → отчёт» или сторонний документ → замечания (добавление/искажение/усиление/потеря) или заключение |

Два сценария входа: транскрипция посещения ИЛИ комплект материалов без транскрипции (тогда первой стадией строится реестр материалов).

## Материалы

- `reference/farm-visit-info-collection-memo.md` — памятка по сбору информации при посещении (что записывать на ферме).
- `reference/review-conclusion-rublevka-example.md` — образец заключения по стороннему отчёту (МТФ Рублевка).
- `reference/technologist-report-bitimsky-example.md` — образец технологического отчёта (СХПК Битимский, v3).
- Оригиналы `.docx` — рядом в `reference/`.
- `examples/bitimsky-02-10/` — эталонный прогон конвейера: транскрипция → карта → отчёт v01→v02→final + 2 ревью. Эталон для проверки скиллов и обучения.
- `examples/visit-13-novotelnye/` — второй прогон: контроль запуска рационов новотёльной секции; цикл сошёлся на первом ревью (только мелкие замечания), хозяйство/дата по транскрипции не установлены — зафиксированы как ограничение. Включает `run-summary.md` (сводка прогона).

## Инварианты

- Якорь реальности (карта или реестр) внутри цикла неизменен; новая версия отчёта строится из якоря + замечаний, не из предыдущей версии.
- Ревьюер не получает историю сборки — проверяет результат, а не объясняет автора.
- Достоверность важнее полноты: ничего не восстанавливать по правдоподобию.
- Финальный слой — экспертная правка технолога; конвейер не выдаёт «окончательный документ».
