# Технологический отчёт по посещению хозяйства

Хозяйство не установлено по транскрипции — новотёльная секция («13 секция») и экономика кормления. Дата посещения не установлена (воскресенье ~2 недели до посещения — запуск новых рационов; посещение в будний день, не среда).

Участники: специалист-консультант по кормлению (сопровождение), руководитель хозяйства, участник (роль не установлена).

*Отчёт составлен по карте посещения, построенной из транскрипции аудиозаписи. Все числовые данные произнесены участниками в разговоре; документы на записи не предъявлялись. Единицы питательности кормосмеси в разговоре не прозвучали и не восстанавливались.*

## 1. Цель посещения

Контроль запуска новых рационов новотёльной секции (потребление, питательность, продуктивность), планирование точки контроля по гинекологии новотёльных (замеры в среду), вопросы экономики кормления на фоне ожидаемого падения закупочной цены на молоко.

## 2. Что зафиксировано

**13-я секция (новотёльные коровы), запуск новых рационов (~2 недели после старта):**

| Показатель | Было | Стало | Источник |
| --- | --- | --- | --- |
| Потребление кормосмеси, кг | 16 (понедельник, замер Ивана) | 18,4 (день посещения, замер) | произнесено специалистом |
| Питательность кормосмеси (единица не прозвучала) | 15,7–15,5 | «за 16» | произнесено специалистом (отобранные пробы) |
| Продуктивность, л | не названо | 32 (держится 2–3 дня) | произнесено специалистом |

**Основное дойное стадо:** сырой протеин кормосмеси 17,4 % (произнесено специалистом).

**По словам специалиста:** коровы 50–60 дней после отёла лечатся по гинекологии; количество и диагнозы не названы.

**Внешний контекст (со слов руководителя):** сегодня ожидается падение закупочной цены на молоко на 5–7 %; «уже везде упали»; необходимость снижать себестоимость кормления.

## 3. Интерпретация

Оценки специалиста, зафиксированные на встрече:

- Запуск рационов 13-й секции идёт «плюс-минус по плану»: потребление и питательность выросли, продуктивность 32 л держится. Полная смена состава группы занимает обычно 3–4 недели, прошло около двух — оценка продуктивности будет корректна после обновления группы. По выходе новотёльных из секции ожидается рост продуктивности по дойному стаду в целом (прогноз, не результат).
- Сырой протеин 17,4 % у основного стада, по оценке специалиста, достаточен «чтобы доить нормальное молоко» — основание решения не менять рацион основного стада.
- По связи кислых солей с гинекологией новотёльных (вопрос руководителя): специалист связь до замеров не подтверждает и не отрицает; совпадение по времени не доказывает причинность. Перекисление может провоцировать проблемы; «если не докислен — в принципе нет». Проверка — замерами в среду (см. §7).
- Версия специалиста (не проверенная): практика быстрого родовспоможения может провоцировать гинекологические проблемы новотёльных; отсылает к прошлым отчётам о посещениях, которые обещал прислать.
- Улучшение энергетики и питательности новотёльных обычно улучшает последующее восстановление по гинекологии; «на это нужно время» (общая закономерность, не результат данного хозяйства).
- По меди: избыток меди утилизируется через печень и «начинает страдать печень»; по словам специалиста, в печени значения «в 10 раз ниже нормы», премикс — источник гепатопротекторов, а не меди. Это обоснование запланированного снижения меди (см. §4); норма документально не предоставлена.

| № | Решение / действие | Статус | Основание |
| --- | --- | --- | --- |
| 1 | Новые рационы 13-й секции запущены (~2 недели назад, в воскресенье); изменения вносил консультант Андрей | выполнено | план разгона новотёльных (прогноз потребления 16 кг — Андрей, со слов специалиста) |
| 2 | Кормосмесь основного дойного стада не менять | принято | сырой протеин 17,4 % — по оценке специалиста, достаточен |
| 3 | Замеры в среду: pH (Иван) и уровень кальция (Анатолий с прибором, совместно с Ваней) по новотёльным; специалист проговорит с Анатолием | запланировано | коровы 50–60 дней после отёла лечатся по гинекологии (со слов специалиста) |
| 4 | Уменьшить медь на 50–80 мг через премикс; специалист свяжется с Андреем | запланировано | интерпретация специалиста: избыток меди утилизируется через печень; по словам руководителя, корректировка по меди не выполнялась |

| 6 | Отчёты (анализы кормов, кормосмеси с комментариями, файлы посещений) сбрасывать руководителю в телеграм и Андрею | поручено | договорённость на встрече |

**Предложения, не принятые в решения:**

- Программа подготовки к жаре: смесь 100 г карбоната калия + 50 г оксида магния + 200 г соды + пропионат хрома (белорусское производство) с мая; основание — опыт других хозяйств прошлого года (со слов специалиста); оценка затрат «в кучу» — около 70 коп./гол. по памяти специалиста, цен не знает. Специалист подготовит расчёт и стоимость к марту.
- Граница дачи антистрессовой смеси по фазе лактации: специалист предлагает «до 150» дней, руководитель согласен разделить «до 200»; на 200–300 днях, по словам руководителя, смысла нет (там МП/ВП рационы, сою не дают). Решение не принято.
- Намерение руководителя: убрать жир «105-й» и пересмотреть «энергопак» (что такое «105-й», по транскрипции не восстановлено).

## 5. Нерешённые вопросы

- Гинекология новотёльных: причина не установлена; масштаб (количество, диагнозы) не назван; проверка — замеры среды и мониторинг динамики.
- Сокращение затрат на кормление: возврат к вопросу через неделю-две; перечень уже сокращённых добавок по транскрипции не восстанавливается.
- Программа подготовки к жаре: ожидается расчёт специалиста к марту; граница дачи по фазам лактации — требует решения.
- По транскрипции не восстанавливаются (не являются данными для решений): значения цен «43, 46, сейчас 47,35»; затраты на хром «на 2,5 тысячи дойных… на месяц 3 тысячи рублей»; перечень продаж и выручки растениеводства без единиц.

## 6. Что запросить

- Название хозяйства и дату посещения (по транскрипции не установлены).
- Документальные данные 13-й секции: замеры потребления (16 кг и 18,4 кг), анализы питательности кормосмеси (включая единицу измерения), продуктивность — для отчёта, который специалист обещал прислать.
- Количество и диагнозы коров на гинекологии — по ветеринарному учёту.
- Состав премикса и текущая дача меди — исходная точка для запланированного снижения.
- Результаты замеров среды.

## 7. Следующий контроль

- **Среда** (дата не установлена): замеры pH (Иван) и уровня кальция (Анатолий с прибором, совместно с Ваней) по новотёльным коровам — точка контроля по гинекологии новотёльных, назначена специалистом.
- Через неделю-две: возврат к вопросу сокращения затрат на кормление (специалист).
- К марту: расчёт и стоимость программы подготовки к жаре (специалист).
- Мониторинг динамики по гинекологии новотёльных — срок не назначен.

## 8. Ограничения и риски интерпретации

- Хозяйство и дата посещения по транскрипции не установлены; все числовые данные произнесены участниками, документы на записи не предъявлялись.
- Единица питательности кормосмеси не прозвучала; «сегодняшнее» значение названо только как «за 16», без точного числа — сопоставление точек ограничено.
- Сведения о гинекологии (50–60 дней после отёла), нормативе мертворождённых (до 6 % по голштинской, «говорит наука» — источник не назван) и значениях меди в печени («в 10 раз ниже нормы») — со слов специалиста, документально не подтверждены.
- Ожидание падения цены на молоко 5–7 % — со слов руководителя; фактическая закупочная цена на записи не названа (фрагмент «43, 46, 47,35» не восстанавливается).
- Транскрипция местами содержит технический шум; фрагменты о продажах, технике, кадрах и части экономических значений не восстанавливаются и в отчёт не включены.

## 9. Подпись

Специалист-консультант по кормлению (имя по транскрипции не установлено). Отчёт подготовлен по карте посещения; перед использованием требует экспертной правки специалиста.
