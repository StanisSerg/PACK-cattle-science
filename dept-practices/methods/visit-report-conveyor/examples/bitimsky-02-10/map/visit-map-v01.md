## 13. Заявленная динамика

- «Если корова не ест, то [пропиленгликоль] помогает» → сравнивается с отсутствием обработки → источник: со слов представителя хозяйства → численных данных нет → динамика заявлена, количественно не подтверждена.
- «После отёла коровы перестали…» (в контексте обсуждения АСТ / «кальциевой») → сравнение с прошлым периодом → источник: со слов представителя хозяйства → численных данных нет → фрагмент обрывается («раньше бегали, длинчевали»), содержание неясно → динамика заявлена, количественно не подтверждена; формулировка требует проверки.
- Рассказ представителя хозяйства о кормовых антибиотиках и состоянии бычков в прошлом («когда я их так кормил, не было такого») → исторический опыт, к текущему состоянию хозяйства не относится.
