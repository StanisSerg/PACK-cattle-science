# 08 — Применение пакета к новому случаю: «жара» и неполный аудит

## Случай (со слов пилота)

Падение молока в хозяйстве. Технолог приехал, сослался на жару, **не сделал полный цикл аудита**: не проверил траншею, из которой брали силос, пропустил разогрев силоса при перевозке. Доложил: «всё в норме, падение из-за жары».

## Применение P1

**Шаг 1 — near-miss:** «Изменение отложено в ожидании данных?» Нет. Хуже: заключение вынесено **без данных** (траншея не проверена, разогрев не измерен). Это не «цикл цел» — идём в шаг 2.

**Шаг 2 — тип разрыва:** визит состоялся, но шаги аудита пропущены; данных для заключения «в норме» не хватало; предметная проблема (разогрев силоса) обнаружена не была. Дословное соответствие **T4 · Полнота**.

**Шаг 3 — фиксация:**
> «Разрыв типа T4 в звене "визит", свидетельство: аудит без проверки траншеи и разогрева силоса; заключение "всё в норме" вынесено без данных по кормовому фактору».

**Новое наблюдение от случая (усиление типологии):** T4 породил **ложно-успокоительный доклад** — «в норме» без полноты. Такой доклад опаснее отсутствия доклада: ведущий успокаивается, предметное окно сгорает. Правило для P2-T4 (добавлено по этому случаю): **заключение «в норме» допустимо только при закрытом чек-листе полноты; без него доклад обязан называться «данных недостаточно»**.

## Применение P2 (T4 → чек-лист полноты визита)

1. Чек-лист аудита при падении молока (наследует CS.METHOD.006), пункты-состояния: «траншея осмотрена, температура силоса в зоне вскрытия измерена — да/нет», «разогрев при перевозке проверен (время от вскрытия, температура смеси) — да/нет», «жара зафиксирована измерением (THI), а не ссылкой — да/нет».
2. Правило вывода: без закрытого чек-листа доклад = «данных недостаточно», не «норма».
3. Оговорка Онтарио в силе: чек-лист требует внедрения (обучение, повторения, контроль) — шаг 09.

## Что случай показал о пакете

- P1 сработал без доработок: тип и звено названы по признакам, near-miss отсечён корректно (ожидания данных не было — была их нехватка по вине исполнителя).
- Случай дал **усиление P2-T4** (правило «нормы» при неполном чек-листе) — перенос подтверждает ценность пакета: новый случай не просто классифицирован, а улучшил паттерн. Это петля E.23 через живое применение.
- Осталось за границей (честно): мотивация технолога («сослался на жару» — удобное объяснение) — предмет LPF/культуры, не паттерна.
