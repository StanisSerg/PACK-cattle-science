## Напоминания

- Гейт (шаг 00): дешёвые выходы до авторства — применить готовый FPF/DPF, тонкий маршрут к источникам, один разовый ответ, честная остановка.
- Критерий переноса: всему классу → DPF; этому предприятию → LPF.
- Три объекта оценки не смешивать: тело — E.21, пакет — E.4.DPF.DA, DRR — E.9.DA. Шкала 0–5, floor = 4.
- Приёмка (слайд 137): предметное изменение + перенос на новый случай + воспроизводимость другим исполнителем + защищаемые характеристики + пакет по E.4.DPF.DA. Один пункт не закрыт → кандидат.
