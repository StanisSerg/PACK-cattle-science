Индивидуальные KPI для персональной надбавки
Статус: draft
Тип: методика мотивации
Охват: 39 сотрудников ОАО «Остромичи»
Принцип: 3–4 простых, наблюдаемых KPI на человека. Оценка 0 / 25 / 50 / 75 / 100%.
Общие правила
• Каждый сотрудник получает 3–4 индивидуальных KPI.
• Оценка по каждому KPI: 0 / 25 / 50 / 75 / 100%.
• Итоговый процент надбавки = среднее арифметическое оценок по KPI.
• Директор выставляет оценки на основе фактических наблюдений, отчётов и
поручений.
KPI сформулированы так, чтобы их можно было оценить без заранее утверждённых
норм — по динамике, срокам, качеству и отсутствию ошибок.
