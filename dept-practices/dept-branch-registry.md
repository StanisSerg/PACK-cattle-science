## Как работать с реестром

1. **Новая ветвь:** следующий свободный ID (`B-NN`), строка в секции своего звена, папка `branches/B-NN-slug/`. Без привязки к звену — не берётся.
2. **Вход в работу:** активная ветвь → «первый неподтверждённый результат» → один вопрос к FPF/агенту.
3. **Результат получен:** обновить строку (новый первый разрыв или статус). Папка и ID не трогаем.
4. **Закрытие:** строка → в «Закрытые» со ссылкой на решение; статус папки не меняется, файлы остаются.
5. **Поиск:** по ID (везде одинаковый), по звену карты (секции), по статусу (🔄/⏳/✅).
