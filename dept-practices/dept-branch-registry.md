## Как работать с реестром

1. Вход в работу: выбрать активную ветвь → взять её «первый неподтверждённый результат» → один вопрос к FPF/агенту.
2. Результат получен → обновить строку ветви (новый первый разрыв или статус).
3. Ветвь закрылась → в «Закрытые» со ссылкой на решение → взять следующую из очереди по вкладу в пользу.
4. Новая идея → строка в очереди с привязкой к звену карты (без привязки — не берётся).
